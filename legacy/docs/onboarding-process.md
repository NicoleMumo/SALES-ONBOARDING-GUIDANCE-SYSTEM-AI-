# Sales-Agent Onboarding Process

## Purpose

Define how a sales agent onboards a customer and what the Transformer needs to learn from the process.

## Basic Process

1. Start an onboarding session.
2. Select the customer's industry.
3. Collect the required customer information.
4. Validate the information in real time.
5. Correct any errors.
6. Complete the onboarding session.

This is only the basic process. The actual steps, fields, and order will be identified from real onboarding processes in different industries.

## What the Transformer Needs to Learn

For each industry, the training data should show:

- The onboarding fields used.
- The order of onboarding steps.
- Required and optional information.
- Validation and verification rules.
- Errors and corrections.
- Different customer paths.
- Conditions that change the process.
- What indicates completion.

## Transformer Role

The Transformer will learn these patterns from the training data and support:

- Step-by-step guidance.
- Real-time validation.
- Completion scoring.
- Risk scoring.

The Transformer should learn the onboarding process from data rather than follow one fixed sequence.
