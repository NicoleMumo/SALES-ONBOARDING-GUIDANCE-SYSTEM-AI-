# Sales-Agent Onboarding Process

## Purpose

Define the basic process a sales agent follows when onboarding a customer.

## Process

1. Start an onboarding session.
2. Select the industry.
3. Enter the required customer information.
4. Validate the information in real time.
5. Correct errors when necessary.
6. Complete the onboarding session.

The exact fields and their order will be determined from real onboarding references for each industry.

## AI System Goal

The system will provide:

- Step-by-step guidance.
- Real-time validation.
- Completion and risk scoring.

The Transformer will learn these patterns from the industry-specific training data.
